# Project 3: Subnetting and VLSM

**Status:** Planned

## Objective
Design an addressing plan for a company network with several departments
using VLSM (Variable Length Subnet Masking), then build and test it
in Packet Tracer.

## Skills Practiced
- IPv4 subnetting and VLSM calculations
- Building an addressing table (network, mask, range, broadcast)
- Assigning IP addresses to router interfaces and end devices
- Verifying connectivity with ping
