# Project 8: Network Troubleshooting

**Status:** Planned

## Objective
Find and fix intentional faults in a working network using a
structured troubleshooting method, and document each problem
and its solution.

## Skills Practiced
- Applying a structured troubleshooting methodology
- Diagnosing IP addressing and default gateway errors
- Using ping, traceroute and show commands to locate faults
- Checking interface status (up/down, shutdown)
- Verifying the network again after every fix
- Documenting problems, causes and solutions
