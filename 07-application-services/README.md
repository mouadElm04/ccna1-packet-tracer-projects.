# Project 7: Application Layer Services

**Status:** Planned

## Objective
Set up common network services (DNS, HTTP, DHCP and FTP) on servers
in Packet Tracer, and connect client devices that use them.

## Skills Practiced
- Configuring DNS, HTTP, DHCP and FTP servers
- Assigning IP addresses automatically with DHCP
- Resolving domain names to IP addresses with DNS
- Accessing a web page from a client browser
- Transferring files with FTP
- Verifying each service from the client side
