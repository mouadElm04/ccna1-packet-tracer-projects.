# Project 5: Static Routing Between Networks

**Status:** Planned

## Objective
Connect multiple networks using two routers and static routes,
so that devices in different networks can communicate.

## Skills Practiced
- Configuring router interfaces with IPv4 addresses
- Setting the default gateway on end devices
- Configuring static routes
- Reading the routing table (show ip route)
- Testing end-to-end connectivity with ping and traceroute
