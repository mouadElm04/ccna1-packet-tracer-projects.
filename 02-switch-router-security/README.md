# Project 2: Switch and Router Security

**Status:** Completed

## Objective
Secure a small office network by hardening the router and the switch:
protected access, encrypted passwords, SSH remote access, and port security.

## Skills Practiced
- Securing console, privileged and remote access
- Password encryption and login banners
- SSH configuration (instead of Telnet)
- Port security on switch ports
- Disabling unused switch ports
