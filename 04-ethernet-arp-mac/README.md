# Project 4: Ethernet, ARP and MAC Table

**Status:** Planned

## Objective
Observe how Ethernet frames, ARP and the switch MAC address table work
in a small network, using Packet Tracer Simulation Mode.

## Skills Practiced
- Understanding Ethernet frames and MAC addressing
- Watching how a switch learns MAC addresses
- Observing ARP requests and replies
- Reading the switch MAC address table and the PC ARP cache
- Using Simulation Mode to trace packets step by step
