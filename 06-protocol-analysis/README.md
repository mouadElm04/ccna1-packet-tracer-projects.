# Project 6: Protocol Analysis (OSI and TCP/IP)

**Status:** Planned

## Objective
Analyze how data travels through a network using Packet Tracer
Simulation Mode, and map each step to the OSI and TCP/IP models.

## Skills Practiced
- Understanding encapsulation and de-encapsulation layer by layer
- Inspecting PDU details at each OSI layer
- Analyzing ICMP (ping and traceroute)
- Comparing TCP and UDP behavior
- Following DNS and HTTP traffic between a client and a server
